# نظام الكتالوجات — Cloud Studio v7

نظام متكامل لإدارة كتالوجات المنتجات: استخراج البيانات من ملفات PDF الخاصة بالموردين، تنظيمها في منتجات وموديلات ومواصفات، ثم تصدير داتا شيت وكتالوجات PDF بهوية بصرية كاملة.

## التشغيل السريع (الوضع المحلي)

1. ثبّت Python 3.11 أو أحدث.
2. أنشئ بيئة افتراضية:
   ```bash
   python3.11 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. شغّل:
   ```bash
   ./run.sh
   ```
   أو على ويندوز: `run.bat`

يفتح المتصفح على http://127.0.0.1:5050

## الوضع السحابي

راجع `README_CLOUD_AR.md` و `deploy.sh` للخطوات الكاملة (Cloud Run + Cloud SQL + Google Drive).

## ملفات مهمة

- `.env.example` — نموذج المتغيرات البيئية (لا ترفع ملف `.env` الحقيقي)
- `requirements.txt` — المكتبات المطلوبة
- `tests/` — الاختبارات (يحتوي على ملف PDF كبير مطلوب للاختبارات)
- `CHANGES_V7_AR.md` — تفاصيل تحسينات النسخة السابعة

## تحذيرات مهمة قبل الرفع على GitHub

- لا ترفع مجلد `data/`
- لا ترفع `.env` أو `token.json` أو `credentials.json`
- ملف `.gitignore` موجود ويستبعد هذه الملفات تلقائيًا

للمزيد من التفاصيل راجع `README.md` (الإنجليزي) وملفات التوثيق العربية الأخرى.
